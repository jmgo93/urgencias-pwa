# Cuestionario para ajustar el plan en una sola respuesta

**Respondido.** Las respuestas recibidas están registradas en [13. Decisiones confirmadas](13_Decisiones_confirmadas.md) y aplicadas a la versión 1.1. Se conserva debajo el cuestionario original como historial; sus etiquetas «propuesta» ya no describen necesariamente el alcance vigente. No hace falta volver a responderlo.

Las alternativas originales permiten rastrear el significado de cada elección. Las capacidades futuras elegidas no se consideran ya validadas ni publicadas; su fase y condiciones se concretan en el registro de decisiones.

**4. ¿Qué derechos de uso del libro y sus imágenes tiene acreditados?**

Efecto: visibilidad del PDF, descarga, traducciones y alcance de las adaptaciones. El trabajo documental privado puede continuar mientras se concreta la distribución futura.
